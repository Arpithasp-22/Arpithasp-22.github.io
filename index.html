PROJECT 1

Ask your sales data a question on WhatsApp

Samrat WhatsApp Sales Analytics Bot
THE PROBLEM

Getting an answer from sales data usually means asking an analyst or opening a dashboard.

WHAT I BUILT

A WhatsApp chatbot. You type a question in plain English and it replies with exact numbers from the sales database. The AI never does the maths. It only writes the question for the database.

PythonSQLiteFlaskTwilioLLM
View code ↗
An LLM works out what the question is asking and writes a SQL query. The query runs on a SQLite database loaded from CSV files, so every number is calculated by the database. Flask receives the WhatsApp message through Twilio and sends the reply back. It supports filters, totals, group-by and ranking questions.

PROJECT 3

        

          
A report card for AI models

          
LLM Evaluation & Monitoring Framework

        

        
THE PROBLEM
Teams put AI models into products without knowing how often they get things wrong.

        
WHAT I BUILT
A test that asks different AI models the same set of questions and grades them on accuracy, making things up, refusing to answer, and speed. "Does it feel right?" becomes a score you can compare.

        
PythonpandasModel adapters

        

          
          View code ↗
        

        
The pipeline runs a curated golden dataset against multiple LLM providers through model adapters. Every response is graded on accuracy, hallucination rate, refusal behaviour and latency (p50 and p95). Results are collected with pandas into a report that can be compared across runs and models.

PROJECT 5

        

          
Finding stars in noisy space photos

          
Astronomical Image Processing for Star Tracking

        

        
THE PROBLEM
Spacecraft can work out which way they're pointing by spotting stars in camera images. That only works if each star is located very precisely, even when the picture is full of noise.

        
WHAT I BUILT
A step-by-step image pipeline that finds stars and streaks (moving objects) in space images, then pins down each star's centre to a fraction of a pixel. It uses fixed, explainable rules, with no AI model involved.

        
PythonNumPySciPyOpenCVMatplotlib

        

          
          View code ↗
        

        
Synthetic images are generated with Gaussian-blurred stars, linear streaks and adjustable noise. Stars are found by thresholding and connected-component labelling. A 2D Gaussian is then fitted around each blob to get a sub-pixel centre, and the fitted widths show whether a blob is round (a star) or stretched (a streak).

      

      

        
TRY IT
Turn up the noise and see how many stars the program still finds.

        
        

        
        
White ring = where a real star is. Blue cross = where the program found it. A ring with no cross is a missed star. Dashed oval = a streak (moving object). Red × = a false alarm.

        

        
"Brightest pixel" is the position of the single brightest pixel in a star. "Refined centre" is a weighted average of the pixels around it, which can land between pixels. Simplified in-browser version, so it uses that weighted average where the repo fits a Gaussian. Images are synthetic, as in the project.
